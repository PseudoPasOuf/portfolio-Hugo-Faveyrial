Reminder, un outil collaboratif pour s'initier à Express !

Objectif:

Pour comprendre le fonctionnement du framework Express, j'ai créé une application web qui permet de créer/modifier/supprimer des tâches.

Résultat:

L'application est complètement fonctionelle. Il y a un système de groupes auxquels assigner les tâches ainsi qu'un système d'authentification des utilisateurs.

Liste des technologies :

  • Express
  • phpMyAdmin
  • SQL
  • HTML / CSS
  • Visual Studio Code

C'était un très bon projet pour progresser en programmation web. Surtout pour se familiariser avec Express et handlebars.
