PotterHead, une appli web pour valoriser les données d'une API REST !

Objectif:

Créer une application web en binôme qui permette de consulter les données d'une API REST (lien vers l'API). Nous devions aussi mettre en place des éléments pour valoriser ses données.

Résultat:

Un site élégant qui répond au cahier des charges. Nous avons intégré une barre de recherche rapidement en utilisant vue.js afin d'améliorer l'expérience utilisateur.

Liste des technologies :

  • API REST
  • HTML / CSS
  • JavaScript
  • Vue.js

Encore un bon exemple de projet qui m'a permis de monter en compétences (surtout avec Vue.js). Nous avons dû travailler rapidement car nous avions peu de temps. Il me faudrait continuer le projet un jour ou deux afin de n'afficher les informations que quand elles sont renseignées sur l'API. Ceci dans le but d'avoir un rendu plus professionnel.
